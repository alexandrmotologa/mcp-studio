Frequently Asked Questions

Do I need to pay monthly subscription fees for LLMs?

No! MCP Studio operates on a 100% "Bring Your Own Key" (BYOK) model. For cloud models (Claude, OpenAI, Gemini), you provide your own API key and pay only for what you consume. If you run Local Ollama (llama3:8b), AI simulation is completely 100% free offline.

How does 1-Click Auto-Discovery work?

MCP Studio automatically reads your existing local configs from Claude Desktop (claude_desktop_config.json) and Cursor IDE (mcp.json) so you can inspect your active servers in 1 click without re-typing environment variables.

Can I test remote HTTP / SSE MCP servers?

Yes! MCP Studio supports both local sub-processes (stdio via Node, Python, UV, Docker, or binaries) and remote Server-Sent Events (SSE endpoints).
